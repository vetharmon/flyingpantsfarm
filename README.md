# Flying Pants Flower Farm Jekyll Starter

A starter Jekyll site for Flying Pants Flower Farm.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open:

```text
http://localhost:4000
```

## Pages included

- Home
- About Us
- Flower Gallery
- Farm Stand
- Current Events
- Sales with Shopify placeholder

## Decap CMS

Admin path:

```text
/admin/
```

This config assumes Netlify Identity + Git Gateway.
